# 城市政策数据说明（M8.0）

## 文件

`city_policies.csv` —— 全国主要城市最低工资 + 上年度职工月平均工资（社平）。

| 字段 | 含义 |
|---|---|
| city | 城市名 |
| province | 省份 |
| min_wage | 月最低工资标准（元） |
| avg_salary_month | 上年度职工月平均工资（元/月，用于经济补偿封顶线 = ×3） |
| data_as_of | 数据截止日期 |
| source | 数据来源 |

## ⚠️ 重要：数据维护责任

本 CSV 为**示例数据**（演示用），数值可能滞后或不准。
**上线前必须由平台管理者按当地人社局最新公布核对更新**（这是 M8 设计的一部分：
数据维护是产品工作，非技术失败——无统一官方 API，人工定期更新是现实做法）。

## 更新流程（平台管理者）

1. 到当地人社局官网查最新最低工资、社平工资公告
2. 更新 CSV 对应行，改 `data_as_of` 为公告日期
3. 重启服务即可生效（工具查询时读取最新 CSV）
